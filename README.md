# Apps & Tools

The central public portfolio for practical apps by Vid567. The initial catalogue contains four products.

## Add the next app

1. Open `apps.js`.
2. Add one object to the `products` list with `name`, `description`, `url`, `cta`, `category`, and `icon`.
3. Add `status` only when an accurate public status should be shown.
4. Reuse an existing icon key or add one small SVG entry to the `icons` object.
5. Test the new link and card at mobile and desktop widths, then publish.

No layout changes are required. The responsive grid automatically supports additional cards.

## Analytics

Analytics is intentionally unconfigured. Add tracking only after creating a dedicated Apps Hub property or stream.
