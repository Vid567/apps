# Apps & Tools

The central public portfolio for practical apps by Vid567. The initial catalogue contains four products.

## Add the next app

1. Open `apps.js`.
2. Add one object to the `products` list with `name`, `description`, `url`, `cta`, `category`, and `icon`.
3. Add `status` only when the product needs a visible release label.
4. Add a matching SVG string to the `icons` object if a new icon is needed.

No HTML changes are required for normal catalogue additions.

## Local preview

Serve the folder with any static web server and open `index.html` through that server.

## Deployment

GitHub Pages should publish from the `main` branch root.
